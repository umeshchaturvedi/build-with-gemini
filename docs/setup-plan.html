Windows-specific gotchas

Differences from the Linux / Qwiklabs lab workstation the upstream guide assumes.

& in the path

The workspace path contains & and spaces, which breaks .cmd shims like npx.cmd. Always quote it; if MCP / npm fails, move the repo to D:\wspace\build-with-gemini.

Firebase MCP

If the firebase server won't start, set "command": "npx.cmd" in .agents/mcp_config.json.

Env vars

Use $env:GOOGLE_CLOUD_PROJECT="…" (session) plus SetEnvironmentVariable(…,"User") to persist. Use Select-String instead of grep.

Skip shim check

Preflight check 6 (xdg-open / shim) is only for the Linux Selkie desktop — skip it on Windows.

No "qwiklabs" ID

Your own project ID won't contain qwiklabs. Ensure billing is on and run set-quota-project for ADC.

Always uv run

Bare adk hits the global Python. Use uv run adk web so project deps resolve.
